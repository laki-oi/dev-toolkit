# Dev Toolkit 🛠️

A lightweight collection of Python developer utility scripts for everyday automation, file processing, and environment inspection.

## Features
- **System Info Extractor:** Quickly audit CPU, memory, and OS runtime metrics.
- **Port Scanner:** Simple TCP socket utility for testing local and network ports.
- **File Batch Renamer:** Regex-enabled file renaming and extension sanitizer.

## Requirements
- Python 3.8+
